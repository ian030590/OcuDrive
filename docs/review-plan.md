# 產品與資安驗收清單

此檔是審查計畫，不是通過證明。執行結果、版本、輸出檔及已知限制應記錄於實際驗證報告。

## 產品驗收

| 情境 | 可觀察的驗收條件 |
| --- | --- |
| 離線啟動 EXE | 無 Python/Godot 開發環境仍可顯示主選單，預設不啟動 bridge、不讀模型、不索取攝影機 |
| 不用眼動儀 | 駕駛、事件、暫停、結束及行車資料匯出正常；眼動結果為未量測，沒有假造視線 |
| 選擇 WebGazer | 只啟動 WebGazer 元件，顯示相機準備、九點校正、五點驗證及不通過時重試的流程 |
| 選擇 Sol | 僅載入 Sol SDK；無裝置、無服務、無必要螢幕映射時顯示具體原因，不能以 scene-camera 座標假裝螢幕座標 |
| 選擇 Tobii | 僅載入 Stream Engine，提示同螢幕 Tobii Experience 校正；無有效注視時不可顯示已準備量測 |
| 切換/關閉來源 | 舊 helper、camera tracks、網頁模型、SDK callback 與網路 socket 確實停止；再次選擇可重連 |
| 路上事件 | seed 固定可重播事件安排，實際可見 onset 與動態 AOI 同時記錄；離螢幕或遮擋時不使用舊框 |
| 操作與復健用途 | 低速、可調時間/難度、鍵盤及控制器、隨時暫停/結束；畫面不震動，音量可關閉 |
| 暫停/視窗變動 | 暫停不推進事件/反應時間/停留時間；resize/DPI/換螢幕使校正失效或明確中止量測 |
| 眼動中斷 | 新資料不足、invalid、序號缺口及來源重連不被補成有效持續注視；沒有把 dropout 當眨眼 |
| TFF | 獨立匯出首入與連續停留 proxy，未偵測為 null，包含演算法、設定、有效/無效/拒收及區間覆蓋 |
| 儲存失敗 | 不可寫目錄、磁碟滿/檔案鎖定需顯示失敗，不能先顯示儲存成功；避免覆寫既有 session |
| 可用性 | 1280×720 及支援最低視窗大小文字不截斷，字級/對比可讀，Tab/Enter/Escape 操作及焦點可見 |
| 成效陳述 | 只呈現當次實測數據，沒有虛構常模、醫療認證、駕駛適任分級或硬體效能保證 |

## 威脅與對抗測試

| 信任邊界 | 檢查/攻擊 | 預期處理 |
| --- | --- | --- |
| localhost HTTP | 非 loopback 綁定、惡意 Origin/Host、跨站 POST、DNS rebinding | 僅 bind 127.0.0.1，檢查允許的 Host/Origin，session token 驗證，拒絕跨站請求 |
| 網頁資產 | `../`、URL 編碼穿越、絕對路徑、query path 混淆 | 只提供明列資產，不讀取任意本機檔案 |
| bridge UDP | 錯 token、錯來源、超大 JSON、NaN/Infinity、巢狀資料、缺欄位、負/倒序時間、重複序號 | 大小/型別/範圍檢查；拒收而不中斷主程式，不讓拒收資料延續停留 |
| 資源消耗 | 無限請求、超量 gaze、過久無結束、過大 body | 有 body/packet/讀取量上限，時限與有界記憶體；不累積無上限 callback queue |
| SDK/DLL 載入 | 當前工作目錄同名 DLL、SDK 搜尋路徑污染、錯架構 | 使用已知絕對路徑與受控內容，無硬體時明確失敗，不降級假樣本 |
| helper 解壓 | 可控路徑、可執行檔被替換、同步啟動競爭、舊版覆寫 | 專用 app 資料目錄、固定檔名、雜湊/完整性與版本檢查、原子寫入；不用 gaze/participant 欄位組執行路徑 |
| 程序啟動 | participant/source/路徑帶引號或 shell metacharacters | 原生 argv 呼叫，source 使用 allowlist，不拼 shell 指令 |
| 結束生命週期 | 遊戲崩潰、bridge 崩潰、瀏覽器先關閉、切換來源中啟動新 session | parent 監測、停止訊息、超時/強制結束、狀態明確；不殘留相機或 SDK |
| 資料匯出 | 路徑穿越 ID、重複檔名、CSV formula injection、內容不完整 | ID 不作任意路徑，唯一 session 名稱、CSV escape/公式處理、失敗保留可恢復資料 |
| 隱私 | 相機/眼動傳到網路、記錄 token、含姓名/影像 | 無預設上傳、不保存相機原始影像；受試者代碼與本機資料位置明示，log 不洩漏 session token |
| 量測同步 | 惡意/延遲 source clock、舊 gaze 配新 AOI、pause 前後拼接 | 保留來源和接收時間，來源映射或明確標示到達時間限制；過期資料不作有效 TFF |

依賴弱掃與程式對抗審查互補：依賴掃描沒有發現已知漏洞不代表程式邏輯或實體眼動儀已驗證。Claude Code 應讀取最終版本並嘗試上述邊界，列出可重現證據、嚴重度、修復位置；任何掃描無法執行時須記錄原因，不寫成已通過。
