## 交叉審查後修正

- 狀態封包和 clock pong 原先消耗 gaze sequence，已分成 transport 與 gaze 序號，避免假造樣本缺口。
- 遲到的視線不能套用最新 AOI；改用單調時鐘估計與短期呈現 frame history，事件結束保留 250 ms 接收窗口，完整結束等待 300 ms。
- 暫停、恢復與尺寸改變切斷停留；不跨暫停內插。不明來源時間或缺歷史畫面只保留無效紀錄。
- SDK 原生無效資料與格式錯誤都不能延續先前停留。無效資料不以零秒、滑鼠或前值填補。
- 紀錄需先確認 raw streams／events 的 flush，再寫最終 metadata；事件檔建立失敗會留下明確不完整狀態。
- 單獨 CR 字元會讓 Godot CSV 產生歧義，先正規化換行，再處理可能的公式文字。
- CanvasLayer 下的控制沒有繼承 root 主題，經實圖發現後明確套用；Sol 標記不得遮住可操作區。
